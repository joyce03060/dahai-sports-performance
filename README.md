# 大海运动表现 · 运动表现教练 Skill

一个基于抖音健身博主「大海运动表现」（省专业队体能教练）**公开内容**重建的 Skill，用于以他的思维框架分析训练问题、编排运动表现训练计划、提供动作教学与饮食建议。输出采用"**计划骨架 → 逐动作讲解 → 饮食建议**"三件套结构，并按用户所打的球类（高尔夫/网球/羽毛球/排球/篮球/足球等）输出针对性专项计划。

> [!IMPORTANT]
> 本项目是基于公开资料与用户提供逐字稿的研究性重建，**不是「大海运动表现」本人、官方产品或私教服务**，也不代表其未公开观点。它不能替代医生、康复治疗师或注册营养师。

## 能做什么

- 以「大海」的 5 个心智模型分析训练与运动表现问题（运动表现标尺 / 先无伤再变强 / 基础复合动作为王 / 功能先于外形 / 少而精）
- 按他的"一周训练计划框架"（2 力量日 + 2 速度日 + 2 恢复日 + 1 休息日）编排周计划，动作、组次、间歇引用其公开计划原话
- **专项运动路由**：根据用户所打的球类输出针对性训练计划（高尔夫/网球=旋转动力链；排球/羽毛球=投掷链；篮球/足球=下肢爆发变向；乒乓球/棒球/橄榄球等）
- 每个动作附**大海本人讲解 + 注意事项**（动作讲解库，逐字稿原话级）
- 深蹲/前蹲/单腿硬拉/侧弓步/哑铃交替卧推/胸椎髋灵活/动态拉伸/核心训练等动作教学
- 饮食建议（优质蛋白/抗氧化水果/椰子水/红薯，补水与早起习惯）
- 处理"整体计划优于单个动作"式的计划编排思路，含组间休息、恢复日、核心训练安排方法
- **HTML 计划输出**：完整训练计划（周计划/专项计划）直接输出为自包含 HTML 文档，可直接保存为 .html 在浏览器查看或打印（含计划骨架表、逐动作讲解卡片、饮食建议、证据徽章）

## 三类证据标签

Skill 会主动区分建议的来源，避免把生成内容冒充本人处方：

- `公开观点`：可由本人公开视频/图文/逐字稿确认（如深蹲标准"臀低于膝+腰椎骨盆中立"、羽毛球"下肢蹬地→躯干→上肢"）
- `框架推断`：根据公开框架和用户信息生成的新方案（如高尔夫/网球等未公开专项）
- `科学边界`：来自运动科学、医疗与营养安全要求的限制

## 使用示例

```text
我想提升弹跳，有举重基础，帮我安排一个一周的计划
```

```text
我打羽毛球，每周能练三次，足背屈受限，帮我排一个周训练计划
```

```text
深蹲怎么才算标准？
```

```text
大海会怎么看待卧推对打排球的作用？
```

为了得到真正个性化的方案，建议同时提供：

- 目标与期限（提升哪项运动表现 / 增肌减脂）
- 年龄、身高、体重及近期变化
- 训练年限和主要动作工作重量
- 每周可训练天数、单次时长和器械条件
- 当前疼痛、既往伤病、疾病或用药情况
- 所打的主要球类/运动（专项路由需要）
- 最近两周的睡眠、压力、食欲和训练表现

## 安全边界

出现急性外伤、明显肿胀或关节不稳，持续加重或夜间疼痛，麻木、放射痛、突然无力，胸痛、异常呼吸困难或晕厥时，Skill 会停止为诱发症状的动作加负荷，并建议及时寻求专业评估。

本项目不提供：

- 医学诊断或伤病康复处方
- 处方药、激素或兴奋剂周期与剂量
- 针对疾病、孕期、未成年人或进食障碍风险的营养处方
- 「大海运动表现」未公开的课程、私教资料或所谓"内部知识"
