# 🏋️ 大海运动表现 · 你的私人运动表现教练

> 🎯 **你是不是也是一位业余球类爱好者**，很想提高竞技水平，却苦于没有教练为你制定、指导训练计划？
>
> 🤕 **你是不是也有伤病、活动度受限**，上网搜过很多功能性训练计划，发现很多动作根本做不了？
>
> 💼 **你是不是也是一名上班族**，训练时间少得可怜，始终找不到一份适合自己的训练计划？

我把省队体能教练「**大海运动表现**」（抖音 150 万粉）蒸馏成了一个 AI 教练 Skill——**让他能为每一个人，制定真正个性化的运动表现提升计划**。 👍

---

## ✅ 它能做什么

输入你的个人情况，它就能像一位省队教练那样，为你量身定制训练计划：

- **私人订制**：根据你的 **年龄、伤病情况、运动项目、场上位置**（排球二传/副攻、篮球中锋/后卫、匹克球网前/后场……）、**有无举重基础**、每周能练几天，生成针对性的计划
-  **专项动力链**：不同运动练不同方向——高尔夫/网球练旋转链，匹克球练快速反应+网前敏捷，排球/羽毛球练投掷链，篮球/足球练下肢爆发与变向，乒乓球练快速反应
-  **位置级定制**：细化到场上位置——副攻重弹跳拦网，控卫重敏捷变向，投手重肩袖投掷链……
-  **每个动作带原话讲解**：计划里每个动作都附「大海」本人的讲解、常见错误和防伤提醒（基于 44+ 条视频逐字稿，非通用话术）
-  **先无伤，再变强**：根据你的伤病和活动度限制自动调整动作，做不了的动作给你降阶替代
-  **三件套交付**：`计划骨架 → 逐动作讲解 → 饮食建议`，输出为精美的 HTML 文档，可直接保存、打印

## 🏷️ 三种证据标签

Skill 会主动区分建议来源，不把生成内容冒充本人处方：

- 🟢 `公开观点` — 可由「大海」本人视频/逐字稿确认
- 🟠 `框架推断` — 根据他的方法论 + 你的个人情况生成
- 🔴 `科学边界` — 运动科学、医疗与营养的安全限制

## ⚠️ 安全边界

出现急性外伤、明显肿胀、关节不稳、夜间痛、麻木、突然无力、胸痛或异常呼吸困难时，请先就医评估。本项目不提供医学诊断、伤病康复处方、药物方案，也不提供「大海」未公开的课程或私教资料。
