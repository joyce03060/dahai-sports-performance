## 〇、总原则（来自大海公开方法论，体系内）

任何专项训练计划 = **通用基础层 + 专项动力链层**，两层顺序不可颠倒：

1. **先无伤，再变强**：先做安全筛查（伤病史/疼痛/活动度缺口），专项动作前必须有准备活动。
2. **基础复合动作是地板**：深蹲家族（含前蹲）、引体、实力推、臀推、核心、髋/胸椎灵活性——这些是所有球类的地基，没有"只练专项不练基础"。
3. **运动表现标尺**：每个专项动作都要回答"它对我在球场上的表现有什么迁移价值"。
4. **少而精，分阶段，保姆式**：一次只聚焦 1-2 个最关键的专项能力，分阶段进阶，覆盖到每一个人。

**生成专项计划的固定结构**（教学话术模板同 SKILL.md 主文件）：
`安全筛查 → 准备活动（针对该运动）→ 基础层 → 专项动力链动作 → 防伤收尾 → 分阶段进阶`

## 一·B 专项原话（公开观点级，来源：《你们想要的篮球、足球、羽毛球的专项功能性训练来了！》逐字稿）

> 原话引用于生成计划时必须使用；与"框架推断"内容区分。开头原话："很多球类爱好者，健身房练得很强，但是到球场上却发挥不出来。不同的球类运动，需要的身体能力，其实是不一样的。"

### 足球（公开观点）
原话要点：
1. "能否在多回合内保持**低重心，却又不失弹性**的下肢功能，是第一个建议你训练的内容。这些训练要求你在30秒到1分钟内，始终保持臀部以及大腿前后侧肌肉群的张力，同样需要配合核心收紧带来的姿态稳定。"
2. 意义："拥有这样的下盘能力，能够避免你在球场上移动当中，重心频繁上下大幅晃动，导致敏捷性和移动速度的缺失。"
3. "再来需要关注到**肩关节周围的爆发力和稳定性**，包括肩胛骨稳定性、肩关节灵活性以及速率。这是卧推等大重量训练，无法给你带来的功能性力量和爆发力。"

→ 对应训练：低重心弹性下肢（30秒-1分钟张力维持：半蹲静力/保加利亚蹲静态/深蹲变式）、肩胛稳定+肩关节灵活（肩胛训练、胸椎灵活）。

### 篮球（公开观点）
原话要点：
1. "篮球运动最重要的能力，就是**垂直方向上的加速、减速能力**。不要觉得跳得高就能够把球打好，**强大的减速制动能力是基础**。能够帮助你随时稳稳地停下来，控制住自己，然后才是随时爆发启动的能力。"
2. "因此，**启动加速的训练和制动减速的训练，都非常重要，都需要多练**。"
3. "再来**对抗能力**，是决定你在篮球运动中表现的关键因素。**单侧负重下的核心控制训练**，是众多高水平运动员训练计划中的选择。你需要把注意力放在肩膀以下，到骨盆以上的躯干区域，维持这一区域在执行动作当中的稳定性。"

→ 对应训练：垂直加减速（跳箱、负重蹲跳、快速起跳+轻柔落地、急停起跳）、单侧负重核心控制（单侧负重弓步蹲起、单臂平板、农夫行走）。

### 羽毛球（公开观点）
原话要点：
1. "羽毛球大量的力量输出，来自于**旋转**。躯干的**旋转爆发力**，**旋转的减速控制**，是非常关键的能力。"
2. "很多人把大量的精力放在练手臂，其实**真正的力量，来自下肢蹬地，经过躯干，再传递到上肢**。"
3. "所以**旋转爆发，旋转减速，力量传导类**的练习，一定要多加练习。"
4. "同时大量的前后、侧向的**急停启动**，对脚踝、膝关节，还有髋部的单侧力量，有着很高的要求。**单腿的力量、稳定、爆发力，同样不可忽视**。"

→ 对应训练：旋转爆发（药球旋转抛、弹力带抗阻旋转、伐木）、力量传导（下肢→躯干→上肢的过顶/挥拍模式：实力推、壶铃摆荡）、急停启动（单脚连续侧向跳、碎步绕标、半蹲前后快速移动）、单腿力量稳定（单腿硬拉、单侧弓步蹲起、保加利亚蹲）。

### 球类通用（公开观点，来自《侧向训练》《脚步训练》逐字稿）
- **侧向训练**："变向、横移、急停、对抗、躲闪，大量动作，都发生在左右的冠状面"；练三样：侧向蹬地发力、减速制动、抗侧倾稳定。"如果你是球类、格斗、田径这类需要频繁变向的运动，一定要把侧向训练纳入你的计划。"
- **脚步训练**（碎步左右/绕圈/绕8字）："不仅发展你的敏捷性和速度，还是提升协调性和身体姿态控制能力的高效方法""轻快和灵巧比用力更重要"。
- **旋转动态拉伸**（弓步转体等6动作）："球类、格斗，大量动作都离不开躯干旋转……缺少旋转方向的动态热身，上场之后转体僵硬，发力不顺，还会增加受伤风险。"

## 二、详细计划骨架（4 个高价值示例，按"动力链分类"）

### A. 旋转动力链型：高尔夫 / 网球（同链，细节不同）

**动力链逻辑**：力量从地面 → 髋 → 骨盆旋转 → 胸椎旋转 → 肩 → 末端释放（球杆/球拍）。旋转链的弱环通常在**胸椎旋转受限**和**抗旋转核心不足**。

**计划骨架（高尔夫示例，2 次/周，单次 45-60 分钟）**：
1. 安全筛查：下背/肩/肘既往伤，胸椎旋转测试（他公开的"测试、原因、纠正"流程）
2. 准备活动：胸椎灵活性 3 动作 + 髋关节灵活 3 动作（体系内：深度讲解3个最实用动作）
3. 基础层：前蹲（体系内：下肢力量强烈建议负重前蹲）3×5 → 单腿硬拉 3×8/侧
4. 专项层：抗旋转核心（帕洛夫推）3×8/侧 → 转髋爆发（药球旋转抛）3×6 → 站姿旋转练习
5. 防伤收尾：肩袖/肘屈肌强化，冷身

**网球差异点**：专项层加重过顶模式（实力推 3×5，体系内）、肩袖外旋强化（发球肩）、侧向箭步（移动）。肘部防伤（网球肘）：前臂伸肌离心。

### B. 投掷链型：排球 / 羽毛球

**动力链逻辑**：力量从髋/下肢 → 核心传导 → 肩胛稳定 → 肩 → 肘 → 腕爆发（扣杀/挥拍）。弱环常在**肩胛控制**和**落地缓冲**（排球）或**弓步深度**（羽毛球）。

**计划骨架（排球示例）**：
1. 安全筛查：膝（髌腱）/踝/肩；落地测试
2. 准备活动：肩胛激活 + 髋/踝灵活
3. 基础层：深蹲/前蹲 3×5（体系内）→ 臀推 3×8
4. 专项层：实力推 3×5（过顶，体系内）→ 药球过顶砸/扣杀模仿 3×6 → 单腿落地缓冲 3×6/侧 → 垂直跳 3×5
5. 防伤收尾：肩袖（外旋/内旋抗阻）、髌腱离心（西班牙蹲）

**羽毛球差异点**：弓步深度优先（弓步变式、髋/踝灵活）、快速启动（HIIT 短冲，体系内心肺耐力）、跟腱保护（离心提踵）。

### C. 下肢爆发变向型：篮球 / 足球（简表）

**计划骨架要点**：深蹲家族 + 前蹲（地基）→ 单腿稳定（ACL 防伤核心，单腿硬拉/箭步）→ 变向（侧向箭步/滑步）→ 踝膝防伤收尾（提踵、腘绳肌）。足球加：腘绳肌北欧弯举（拉伤预防）。篮球加：垂直跳与落地训练。

### D. 快速反应旋转型：乒乓球（简表）

旋转核心 + 胸椎灵活 + 肩部稳定 + 反应 HIIT；腰/肩/腕防伤。

## 三、专项计划生成流程（SKILL.md 使用）

当用户说"我打[某项球]"时，按此流程：

1. **定位运动** → 查上表，确认动力链类型（旋转/投掷/下肢爆发/快速反应）
2. **安全筛查** → 问该运动的高发伤部位（见"常见损伤风险"列）+ 用户既往伤
3. **三层组装** → 准备活动（针对性）→ 基础层（体系内动作）→ 专项层（动力链动作）
4. **表达** → 用大海教学话术模板输出（钩子→结论→为什么→怎么做→降门槛），分阶段
5. **标注** → 专项动作标「框架推断」（大海未公开过），基础动作标「公开观点」，风险限制标「科学边界」
